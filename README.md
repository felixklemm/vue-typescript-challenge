[English](#english) · [Deutsch](#deutsch)

## English

### Background

This repository contains a small Vue 3 component written with the Composition API and TypeScript. The implementation contains several issues.

### Your task

Review [`index.vue`](./index.vue) and identify as many problems as possible. Explain each issue briefly and, where helpful, describe how it could be addressed.

Consider different kinds of problems, including:

- TypeScript and type-safety issues;
- possible runtime errors;
- logical or behavioral problems;
- Vue-specific issues and frontend best practices;
- readability and maintainability concerns;
- relevant edge cases.

Do not change or write any code. This is an analysis and discussion exercise only.

### Evaluation criteria

We will primarily look at:

- the ability to spot relevant issues quickly;
- understanding of TypeScript and Vue 3;
- awareness of runtime behavior and edge cases;
- clarity and precision of the explanations;
- the ability to prioritize findings by impact.

### Notes

- Focus on analysis rather than proposing a complete redesign.
- You are not expected to find every issue within the available time.
- Feel free to state assumptions where the intended behavior is unclear.

**Time limit:** 5 minutes

## Deutsch

### Hintergrund

Dieses Repository enthält eine kleine Vue-3-Komponente, die mit der Composition API und TypeScript geschrieben wurde. Die Implementierung enthält mehrere Probleme.

### Aufgabe

Die Bewerberin überprüft [`index.vue`](./index.vue) und identifiziert in der verfügbaren Zeit so viele Probleme wie möglich. Sie erklärt jedes Problem kurz und beschreibt, falls hilfreich, wie es behoben werden könnte.

Dabei sollen unterschiedliche Arten von Problemen berücksichtigt werden, darunter:

- TypeScript- und Typsicherheitsprobleme;
- mögliche Laufzeitfehler;
- logische oder funktionale Probleme;
- Vue-spezifische Probleme und Frontend-Best-Practices;
- Lesbarkeit und Wartbarkeit;
- relevante Grenzfälle.

Die Bewerberin soll keinen Code schreiben oder verändern. Es handelt sich ausschließlich um eine Analyse- und Diskussionsaufgabe.

### Bewertungskriterien

Wir achten insbesondere auf:

- das schnelle Erkennen relevanter Probleme;
- das Verständnis von TypeScript und Vue 3;
- das Bewusstsein für Laufzeitverhalten und Grenzfälle;
- klare und präzise Erklärungen;
- die Priorisierung der gefundenen Probleme nach ihrer Auswirkung.

### Hinweise

- Der Fokus liegt auf der Analyse, nicht auf einem vollständigen Redesign.
- Es wird nicht erwartet, dass die Bewerberin in der verfügbaren Zeit jedes Problem findet.
- Bei unklarem beabsichtigtem Verhalten darf die Bewerberin ihre Annahmen nennen.

**Zeitlimit:** 5 Minuten
